# 本地数据目录

此目录用于本机离线视觉作业和演示。仓库跟踪数据说明，原图、权重、视频、运行数据库及生成资产留在本地。

- 按来源管理仿真图、公开序列和自有素材。记录公开数据的链接、修订和可分发条件。自有场景保留视频原件与关键帧清单。
- 一次重建使用一个布景版本内的有序照片。移物后保存新版本，保留旧照片及资产关联。每次运行记录工具版本、配置、注册与训练清单。
- 区分原始高斯 PLY、浏览用 SOG、点云 GLB 和单文件离线展示。只把可公开分发的样例用于交付包，有署名要求的素材随包记录出处。
- 大体积模型、现场视频、原图和中间产物沿用本地共享方式。 [样例与实测](../docs/experiments/public-sample-benchmark.md) · [交接约定](../docs/design/platform-architecture.md)
