# 绕物成景 · 离线空间扫描系统执行方案

**版本** v0.2　　**状态** 当前执行基线　　**更新日期** 2026 年 11 月 23 日

## 1. 目标与交付范围

「绕物成景」是一套带仿真工作台的空间扫描系统。用户在工作台内摆放展品、移动球形机器人，通过球上相机从多个机位取景，观察点云随补拍完善，再重建可交互的 3DGS。系统还支持加载预先重建的公开高斯场景，以及用公开原始照片或用户素材生成新的 3DGS。

**当前阶段先做视觉模块。** 单机运行，预先准备权重、工具和样例。先用命令行、批次文件和现有查看器验证点云与 3DGS，再设计仿真工作台的界面和服务。深度图按需作为定位点云问题的诊断产物。

| 优先级 | 工程交付 | 范围 |
| --- | --- | --- |
| P0 视觉基线 | 本地多图点云、原图到 3DGS、预生成高斯资产浏览 | 用同组公开照片验证两条计算链路。留存输入、参数、产物与耗时。 |
| P1 扫描工作台 | 可移动的虚拟球及展品、球载相机、分批补扫、结果浏览 | 扫描一件有纹理和背面标记的虚拟展品及附近桌面。核对换位后的 RGB、移物后的布景版本，以及各结果的输入来源。 |
| P1 自有素材 | 用户导入照片或 MP4，在本机重建实际空间 | 首个实拍试验覆盖书桌和相邻角落。工作台也能加载独立的公开室内高斯资产，演示更大空间的连续视角浏览。 |
| 后续扩展 | 自有域名下的网页发布、云 GPU 作业、实体球、整屋扫描 | 静态资产发布与远程算力可独立落地，按实际测试再确认部署方式。 |

## 2. 仿真工作台操作

1. **摆放。** 用户在仿真空间内移动球或展品。总览即时反映场景内对象的位置，球载相机随球的位姿更新，允许切换到其当前画面。
2. **换位补扫。** 保持展品、桌面和灯光稳定。移动球至正面、过渡、侧面、背面机位，停稳后保存相机实际渲染出的 RGB。首图和随后的多图批次分别生成点云，通过原图核对补拍带来的可见表面。两批结果先独立显示，叠加前验证坐标与尺度。
3. **移动展品后重新扫描。** 物体的位置或朝向发生变化时建立新的布景版本。新照片进入新版本，历史照片和结果继续对应原先的摆放和机位。一次重建使用同一个布景版本内的照片。
4. **重建与浏览。** 冻结最终照片清单，后台完成注册、优化和导出。网页加载高斯后可拖动、缩放，或在覆盖区域内连续移动。打开预生成公开资产时标明来源和生成方式。

**验收场景**　从正面经侧面绕到背面。原图能核对新机位，点云能看到新增的背面轮廓，最终高斯中能辨识背面标记。再挪动展品，检查取景更新以及旧照片、旧产物是否仍关联原布景。

## 3. 素材与重建前置条件

| 输入 | 处理方式 | 前置条件与验收 |
| --- | --- | --- |
| 已重建的公开 `SOG` 或高斯 `PLY` | 直接在本地查看器打开。需要精简交付时，用同一高斯资产转 SOG 对照。 | 查看器支持该格式，记录来源、版本和授权。加载后可移动视角。 |
| 公开或用户提供的 `JPG/PNG` | COLMAP 注册相机，Brush 重建。同批图也可交 DA3 生成点云。 | 场景静止、相邻图清晰且有重叠，相机处于多个位置。小场景按 24–40 张、长边约 1200 px 起测。关键区域照片进入同一子模型。 |
| 普通手机 `MP4` | FFmpeg 抽取清晰、有位移且重叠的关键帧，复用图片入口。 | 建议 1080p、固定焦段、移动缓慢。首测书桌和相邻角落，从两个实拍覆盖的视角核对结构和细节。原地转向主要增加朝向覆盖，三维重建依赖位移形成的视差。 [视频处理](https://docs.nerf.studio/quickstart/custom_dataset.html) · [COLMAP 采集](https://colmap.github.io/tutorial.html) |
| 已拼接 360° 全景图 | 可作为补充素材，用热点连接多个固定站点。 | 验收定点环看和换站。室内连续移动视角用 3DGS 资产另行验证。 [全景导览](https://pannellum.org/documentation/examples/tour/) |

**3DGS 质量与速度**　用同一资产和固定镜头对照 PLY、SOG，核对背面标记、轮廓和遮挡边界。记录文件大小、首帧、首次可拖动和移动时的帧间隔。照片注册、场景优化及导出按阶段计时。实时交互发生在已生成资产加载之后。

## 4. 模块与交接

| 模块 | 方案 | 交付 |
| --- | --- | --- |
| 点云 | DA3-BASE 联合估计深度与相机参数。分别处理首图和多图批次。`process_res=504`、展示上限 20 万点作为起点。 | 彩色点云 GLB、输入与参数清单。深度可视化按需导出。 |
| 3DGS | COLMAP 注册、Brush 优化、SplatTransform 压缩。记录注册图、训练图和留出图。 | 注册清单、完整高斯 PLY、SOG、日志及阶段耗时。 |
| 仿真采集 | 相机固定于球体，随球体同步更新。在工位保存 RGB 和机位信息。虚拟相机参数可用于对齐诊断。 | 图像、机位、布景版本、拍摄顺序。 |
| 结果浏览 | 用现有点云与高斯查看器做离线验证。产物格式稳定后接到内嵌工作台。 | 本地交互页、单文件演示，后续接入场景、机位及批次操作。 |

视觉阶段以文件交接。场景可包含多个布景版本，每次计算绑定冻结的有序照片清单。输出记下来源、算法版本、参数和对应批次。失败留存报错与原输入，成功并验证文件后发布产物。工作台集成时再确定服务接口和任务状态实现。 [系统架构](platform-architecture.md) · [源码布局](../../src/README.md)

## 5. 实施顺序与验收

| 阶段 | 任务 | 通过条件与证据 |
| --- | --- | --- |
| V0 项目工程化 | 同步 README、执行方案、架构、实施指南和交付清单。 | 项目入口能找到当前范围、已有结果与下一阶段。 |
| V1 点云 | 固定公开素材，运行首图和多图，保存输入顺序、耗时和两份 GLB。必要时用深度图定位问题。 | 资产可打开，按原图和机位检查覆盖变化。点数记录作产物规模参考。 |
| V2 3DGS | 公开原图复跑注册、重建和压缩，对照完整与压缩资产。 | 同一照片批次可追溯到可加载的 PLY/SOG，保存注册记录和固定视角截图，断开外网仍可浏览。 |
| V3 仿真工作台 | 实现球、物体摆放和 RGB 取景，接上视觉作业与查看器。 | 同一静态布景从正面补到背面。至少一张标记清晰的背面图参与高斯优化，另选过渡视角留出检查。移物后新图匹配新布局，历史产物可回查。 |
| V4 自有素材 | 用用户提供的照片或 MP4 试扫书桌角落，同时验收公开室内场景的浏览。 | 可回查关键帧与注册结果，相隔位置的视角均能核对书桌和角落。失败时记录阶段及需补拍位置。 |

V1、V2 可并行。所需输入和输出明确后，V3 再接工作台。用户素材到位后可先走同一图片入口。
