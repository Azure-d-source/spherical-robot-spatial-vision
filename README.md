# 绕物成景 · 离线空间扫描系统

面向第四届“东软教育杯”人工智能应用方向的空间视觉项目。系统规划一个内嵌仿真工作台，可摆放虚拟展品、移动球形机器人并用球载相机从不同位置取景。补拍后的照片用于点云对比，同批原图可重建成可交互浏览的 3DGS。工作台也将支持公开高斯资产回看，以及从公开图片或自有照片、视频生成新场景。

## 当前阶段

目前先验证 **本机多视角点云、照片到 3DGS，以及已生成场景的离线浏览**。点云与 3DGS 分别读入有序 RGB 照片，深度图按需作为诊断。首版使用本地文件、视觉作业与现成查看器复现，视觉产物稳定后再设计工作台界面与服务。后续可用自有域名分阶段发布静态展示或接入云 GPU。

| 模块 | 已验证 | 下一步 |
| --- | --- | --- |
| 多视角点云 | DA3-BASE 已对公开照片输出单图和多图彩色点云。 | 固定输入与参数，做可追溯的批次对比。 |
| 3DGS 重建与浏览 | COLMAP 注册了公开样例的 32 张图片，Brush 生成模型。同一轮高斯资产从 24.55 MiB PLY 压到 1.89 MiB SOG，并在 Edge 验证离线拖动和移动视角。 | 固定注册、重建、导出与画质的对照流程。自有素材到位后首测书桌与相邻角落。 |
| 仿真采集 | 4 个虚拟机位曾产出不同 RGB，并完成本机点云试跑。 | 后续接上可移动的球载相机与展品，移物后使用新的布景版本。 |
| 工作台部署 | 已验证独立的离线高斯查看页。 | 视觉模块完成验证后，集成仿真、照片批次、点云和高斯查看。 |

实时渲染指浏览器加载高斯资产后的交互。照片注册、3DGS 优化和导出独立计时。室内预生成高斯可用于连续视角浏览，定点 360° 全景和热点跳转为独立展示方式。
